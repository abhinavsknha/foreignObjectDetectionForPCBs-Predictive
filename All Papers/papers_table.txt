[1] Ye et al., "A Lightweight PCB Defect Detection Algorithm Based on an Improved YOLOv11s," IEEE Access, 2026. | Address limited accuracy of PCB defect detection while balancing lightweight design for real-time deployment on edge devices. | EfficientViT lightweight backbone replacing YOLOv11 backbone; C3k2_Faster_EMA module (FasterNet PConv + EMA) in neck; Inner_Wise_IoU loss combining auxiliary bounding boxes with dynamic focusing. | Pros: 61.7% parameter reduction, 63.9% computation reduction, 58.3% smaller model, 227.54 FPS. [2] Li et al., "Lightweight PCB defect detection method based on SCF-YOLO," PLoS ONE, Apr. 2025. | Reduce large model size and slow detection speed in real-time PCB defect detection for resource-limited industrial deployment. | MobileNetv3 compact backbone replacing YOLOv8 backbone; SCF module with learnable weight fusion for multi-scale feature fusion; combined CIoU+GIoU loss function. | Pros: Lightweight, efficient for edge deployment, good speed-accuracy balance. Cons: May lack robustness compared to heavier models; robustness trade-off noted. | Achieves effective balance between speed, accuracy, and model size; suitable for edge computing and embedded platforms.
[3] Kong et al., "GESC-YOLO: Improved Lightweight PCB Defect Detection Based Algorithm," Sensors, May 2025. | Address excessive model size and parameter complexity in PCB defect detection for lightweight mobile deployment. | YOLOv8n modified with C2f-GE lightweight module in backbone; GSConv hybrid convolution + VoV-GSCSP module for Slim-neck structure; retains high-precision detection. | Pros: Reduced computational parameters, increased feature map channels for better extraction. Cons: Some accuracy trade-off for lightweight design. | Maintains high-precision detection rate while significantly reducing model parameters and resource consumption.
[4] Chu et al., "A lightweight PCB defect detection method based on group convolution and adaptive pruning," PeerJ Comput. Cons: Pruning may cause slight accuracy degradation in edge cases. | Outperforms baseline YOLOv8n across parameters, computation, and accuracy on enhanced PKU-Market-PCB dataset.
[5] Yin et al., "MAS-YOLO: A Lightweight Detection Algorithm for PCB Defect Detection Based on Improved YOLOv12," Appl. Cons: Complex architecture may increase computational demands. | Consistently delivers superior performance across multiple PCB defect datasets, meeting real-time industrial detection requirements.
[6] Selvam et al., "YOLO-DefXpert: An Advanced Defect Detection on PCB Surfaces Using Improved YOLOv11," IEEE Access, Aug. 2025. | Improve PCB surface defect detection accuracy under complex background conditions with compact board layouts. | Improved YOLOv11 architecture with enhanced feature extraction; optimized for tiny defect detection on HRIPCB dataset; aggregate loss function combining box, class, and distribution focal loss. | Pros: 99% mAP50 on HRIPCB, strong generalization. Cons: Specific dataset focus may limit generalizability. | Achieves mAP50 average of 99% on HRIPCB dataset; lower loss convergence than original YOLOv11; superior detection across all six defect classes.
[7] Chen and Liu, "A High-Accuracy PCB Defect Detection Algorithm Based on Improved YOLOv12," Symmetry, Jun. 2025. | Address high small-object miss rates, frequent false positives, and poor real-time performance in PCB defect detection. | YOLOv12 + GAM (Global Attention Mechanism) in A2C2f module; HWD (Hybrid Weighted Downsampling); BiFPN; PPA (Parallel Perception Attention) detection head; Normalized Wise-IoU loss. | Pros: 5.8% mAP@50 improvement over baseline, effective micro-defect detection. Cons: Increased computational complexity affects real-time performance on embedded devices. | mAP@50 and mAP@50:95 increased by 5.8% and 3.9% over YOLOv12n; effective multi-module synergistic optimization for micro-defects.
[8] Chen et al., "Small defect detection in PCBs based on multiscale edge strengthening and improved YOLOv10," Sci. [9] Wang et al., "PCB Defect Detection Based on Improved YOLOv8n," Proc.
